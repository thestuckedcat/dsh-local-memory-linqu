### N-1（Important，新）纠正"新事实保存"把整条用户消息直接写成 `decision` 记忆，绕过提取/语义校验且无去重

- `plugin/correction.mjs:60-70`：只要检测到短语且有 cited 记忆，就把当前输入 `input.slice(0,4000)` 原样 `store.put({kind:'decision',origin:'user'})`，不看消息是否包含可保存事实、是否只含"上次理解错了"这类元评论、是否与已有记忆重复；随机 UUID 使重复纠正产生多条重复记忆；该写入也不走 `abstracts.noteChange`（与 README §6/mechanisms §6.4-26 已记录的 "绕过产品写入路径不累计 dirty" 同类）。

- 现有测试 `tests/correction.test.mjs:42-48` 只覆盖一次正常纠正文本，未覆盖仅短语/超长/重复/含无关内容消息。
