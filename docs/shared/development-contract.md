## 交付和依赖

- 八目录各有 README.md、PLAN.md。README 是模块职责和入口，PLAN 是可逐项执行的后续开发任务；现有调查/设计/评审仍在 docs。
- skill 负责 Agent 的操作和判断流程；plugin 负责 DSH 的 Host/client 工具、会话钩子与 UI；MCP 是可跨 Harness 调用的本地可执行工具服务；profile/bundle 负责已选组件的装配。一个能力可有必要的组合，不能用说明文字替代状态、协议或权限实现。
- 每模块先以独立合成 fixture/临时 profile 运行，不以其他七项已实现为前提。跨模块集成先用接口替身；08在第三阶段先交付框架并接05/07，后续逐项接入和验证，不循环依赖。
- 不默认复制或 fork 整个上游。先锁定允许复用的版本、许可、源码/发布字节和依赖，记录 source lock；优先薄适配。是否修改现有 H 盘项目在相应实施任务中明确，不在规划阶段提前执行。
- 不初始化 Git、创建提交、建远端仓或发布包，除非后续任务确实需要且已有授权。当前工作区没有 Git 基线，审查使用文件摘要。

## 网络、秘密与模型

- 只允许批准的模型 API，以及当前任务明确指定的可信目标；目标登记包含地址、协议、端口、用途。不扩大为全部公网、全部私网或任意 Provider。
- 记忆提取/总结/反思/去重已获用户允许，优先使用 DSH 已配置 Provider；后台任务固定入队时的 route、scope、用途和来源。禁止未知 Provider/环境 key/CLI fallback。
- 存储、索引、检索、管理和原始证据本地部署。embedding/rerank 默认本地预置或词法降级；不引入托管记忆/代码索引/公共图示服务。
- 默认无遥测、通知上报、版本检查、自动更新、权重下载、Git 远端同步、公开隧道；必要制品优先离线，网络制品源只能是明确登记的可信环境服务。
- 密码、cookie、token、私钥由本地凭据引用消费，不进入模型参数/结果、日志、截图、索引或长期记忆。不能用仅按键名脱敏替代完整输出边界。
- 网络策略覆盖宿主、所有子进程、浏览器资源、重定向、DNS/代理和远端命令。禁按钮或写 localhost 不构成最终隔离；固定构件静态审查与负向网络测试均需通过。

## 身份、状态与证据

- 运行/任务/事件带稳定 ID 和 generation；超时、断线或部分写入不伪装完成。存在副作用的命令不自动重放，无法确认结果标 outcome_unknown。
- 代码身份包括 repo/root、commit/dirty、构建变体、架构、工具链、编译数据库和生成头摘要；事实、推断、候选和未知分开。图示和记忆不能提高事实可信度。
- scope 在读取、检索、模型提取前过滤。缺失项目上下文时不自动晋升 global；跨项目或多仓共享必须显式登记。
- 03 的回退/删除、04 的学习索引与 05 的记忆派生不构成自动全局事务。跨模块通知用版本化事实事件及本地 journal，消费者幂等、检测丢失并可按本地状态重核。
- 拟议事件字段：`schema_version=1, event_id, kind, source_capability, scope_ref, session_ref?, operation_id, generation, affected_refs, outcome, before_snapshot?, after_snapshot?, occurred_at`；kind 为 `session_surface_rewound | workspace_files_restored | session_removed`，outcome 为 `completed | partial | outcome_unknown`。affected_refs 仅登记根内的非秘密引用/摘要，不携带全文。持久 outbox 发布时点、保留期限、投递重放策略由 03 的实现合同冻结，其他模块可独立用 fixture 测试。
- before_snapshot/after_snapshot 可省略或为 null；有值时必须是当前登记范围内的非秘密快照引用，不解释为已完成全局快照。session_ref 可省略；涉及单会话的生产者必须提供，消费者不能用缺省值猜测另一会话。
- 忘记分归档/停召回/物理删除；保留无正文 tombstone/generation，阻止在途结果、重建或旧备份复活。说明备份窗口，不能承诺撤回模型服务已收到的请求。
